# Ranjeet Tiwary - Professional Portfolio

Welcome to the official portfolio repository for **Ranjeet Tiwary**, an experienced Business Development Professional and Market Analysis Expert. This project showcases professional achievements, skills, and work history through an interactive and modern web interface.

## 🚀 Live Demo
*(Link will be available after Vercel deployment)*

## ✨ Key Features

-   **3D Hero Section**: Interactive 3D animated background featuring a parallax effect on the profile image, built with custom React hooks and Framer Motion.
-   **Work Journey Timeline**: A detailed professional timeline (PlanetSpark, WhiteHat Jr, Skill Nation) with integrated **PDF and Image Previews** for performance dashboards and talent reviews.
-   **Interactive UI**: Smooth animations and transitions powered by `framer-motion`.
-   **Responsive Design**: Fully optimized for desktop, tablet, and mobile devices using Tailwind CSS.
-   **Asset Management**: Centralized asset handling for certificates, badges, and profile images.

## 🛠️ Tech Stack

-   **Frontend**: [React](https://reactjs.org/) (Vite)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Animations**: [Framer Motion](https://www.framer.com/motion/)
-   **3D Effects**: React Three Fiber / Custom CSS 3D Transforms
-   **PDF Handling**: Native iframe integration with toolbar controls disabled for clean viewing.

## 🔧 Local Development

1.  **Clone the repository**
    ```bash
    git clone https://github.com/remotehive-dev/Ranjeet-Tiwary.git
    cd Ranjeet-Tiwary
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Start the development server**
    ```bash
    npm run dev
    ```

## 🚀 Deployment (Vercel)

This project is configured for seamless deployment on Vercel.

1.  Push changes to the `main` branch.
2.  Connect the repository to Vercel.
3.  Vercel will automatically detect the Vite framework and deploy.
